# Customer commitment letter (one-pager)

**Product:** Orbit FMS  
**Date:** 2026-10-24

## What we commit now — Program A

| Deliverable | Meaning for you |
|-------------|-----------------|
| Verticals + asset type catalog | Industry templates (hospital, hotel, …) with shared aging / PM defaults |
| Printable asset QR | Stickers that open the right asset; guests can report a problem without seeing history |
| Parts on the bill + VAT | Catalog parts used on a work order appear on the invoice with your VAT rate |
| Downtime / failure codes (A5) | Structured history so later analytics are possible |

**Tax note:** Configurable VAT per tenant. **Official e-invoicing (ZATCA / ETA) is a priced add-on**, not in the first ~6 months.

## Roadmap — Program B

Published as roadmap, not a fixed go-live date in this package:

- SLA policies and breach alerts
- Engineer / technician KPI dashboards
- WhatsApp notifications + **human-triaged** inbound requests

## Separately priced — Program C (AI SKU)

After ≥3–6 months of labelled work-order / failure data:

- Speech-to-text intake
- AI draft work order (you confirm before save)
- Prediction models
- **Asset Health Twin** view (status, risk, PM due, history) — not a full BIM/IoT twin

## What we are not promising in this package

- Stock ledger / warehouse inventory (optional A3b only if you require on-hand qty)
- Auto-created work orders from chat or AI
- BIM / IoT digital twin
