# Orbit Periapsis — logo variants

Selected mark: open orbit ring with the asset seated in the periapsis gap.

| File | Use |
|------|-----|
| `orbit-symbol.svg` | Default color — Harbor Navy `#123056` + Copper `#e85d04` (matches app `OrbitLogo`) |
| `orbit-symbol-blue-orange.svg` | Blue `#1d4e89` + orange `#e85d04` (primary-500) |
| `orbit-symbol-white.svg` | **Login tone** — white ring `#f7f9fc` + orange `#e85d04` (same as `OrbitLogo` `tone="onDark"`) |
| `orbit-symbol-black.svg` | Solid black — place on light backgrounds |
| `orbit-lockup*.svg` | Same colors with ORBIT wordmark |

App favicon / PWA icons in `public/icons/` use the default color mark.
