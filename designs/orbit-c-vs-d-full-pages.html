UX verdict

C wins consistency: one nav model, faster to ship, desktop stays familiar. Field path ≈ Home → Work → detail → Continue report.

D wins field speed: Start next first, large Complete work, Scan/Time first-class. Cost: two shells + role gate before chrome.

Recommendation: ship C for the PWA pilot (already coded). Prototype D’s Queue / Start next pattern inside C’s Work tab as the next UX experiment — borrow D’s action hierarchy without forking the shell.
